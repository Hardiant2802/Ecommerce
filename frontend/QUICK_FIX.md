### LÀM NGAY ĐỂ THẤY THAY ĐỔI:

#### ⭐ Cách 1: HARD REFRESH (Nhanh nhất - Làm ngay!)
```
Windows/Linux: Ctrl + Shift + R
hoặc: Ctrl + F5

Mac: Cmd + Shift + R
```

#### Cách 2: Clear Cache trong DevTools
1. Bấm F12 mở DevTools
2. Right-click vào nút Refresh của browser
3. Chọn "Empty Cache and Hard Reload"

#### Cách 3: Disable Cache (cho lần sau)
1. Bấm F12
2. Tab Network
3. Check ☑ "Disable cache"
4. Giữ DevTools mở

### TẠI SAO F5 KHÔNG ĐỦ?

Browser cache JS/CSS với hash names.
Hard refresh tải lại TẤT CẢ.
