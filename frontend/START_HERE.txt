⚡ QUICK START (3 Steps)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Install dependencies:
     $ npm install

  2. Copy environment file:
     $ cp .env.example .env.local

  3. Start development server:
     $ npm run dev

  → Open http://localhost:3000
