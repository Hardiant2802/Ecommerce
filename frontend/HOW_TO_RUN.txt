📖 HƯỚNG DẪN:

1. Mở trình duyệt
2. Vào địa chỉ: http://localhost:3004
3. Hard refresh (Ctrl+Shift+R hoặc Cmd+Shift+R)
4. Xem trang web đẹp với CSS đầy đủ!

🔧 NẾU CẦN RESTART SERVER:

cd /home/huydz895/Ecommerce/frontend
npm run dev

Server sẽ tự động chọn port có sẵn (3000, 3003, 3004...)

• Products:       http://localhost:3004/products

• Cart:           http://localhost:3004/cart
